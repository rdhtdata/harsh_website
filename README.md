# Harsh Tripathi — Portfolio Website

Premium, modern personal portfolio website for **Harsh Tripathi**, AI Solutions Engineer & Technical Founder.

Built with **React 19**, **Vite**, **Tailwind CSS**, and **Lucide Icons** following an editorial, minimalist, and system-first engineering aesthetic.

---

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS 4 with custom typography scale and fluid `clamp()` tokens
- **Typography**: Space Grotesk (Display/Headings), Inter (Body), JetBrains Mono (Technical/Metadata)
- **Icons**: Lucide Icons + custom inline SVGs
- **SEO & Structured Data**: OpenGraph, Twitter Cards, Schema.org JSON-LD (Person & WebSite), Sitemap & Robots.txt

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
